# 教学指南

## 一、课程目标

通过本项目，学生可以直观理解：

- 图像在计算机中的基本表示
- BGR 与 RGB 的区别
- 图像平滑
- 边缘检测
- 颜色量化
- K-Means 聚类
- 双边滤波
- 多算法流水线

## 二、推荐实验一：高斯平滑

### 实验目的

观察不同卷积核大小对图像平滑效果的影响。

### 操作

只勾选：

`平滑处理`

逐渐将模糊程度从 3 调整到 31。

### 思考

1. 为什么核越大，图像通常越模糊？
2. 为什么过度平滑会损失细节？
3. 高斯滤波为什么能够降低高频噪声？

## 三、推荐实验二：Canny 边缘检测

只勾选：

`边缘提取`

分别调整低阈值和高阈值。

### 思考

1. 阈值过低会发生什么？
2. 阈值过高会发生什么？
3. 为什么边缘检测前通常需要进行平滑？

## 四、推荐实验三：K-Means 色彩量化

选择：

`风格化 → 抽象主义`

改变颜色数量 K。

### 思考

1. K=2 与 K=15 的结果有什么区别？
2. 为什么减少颜色后会出现明显色块？
3. K-Means 在这里解决的本质问题是什么？

## 五、推荐实验四：算法组合

同时开启：

`平滑处理 + 抽象主义 + 边缘提取`

观察最终结果。

### 重点

本实验用于理解图像处理流水线：

```text
输入
 ↓
预处理
 ↓
特征/颜色处理
 ↓
边缘增强
 ↓
输出
```

改变算法顺序可能得到不同结果。

## 六、教师可扩展内容

可以要求学生在现有项目基础上增加一种算法，例如：

- 二值化
- 直方图均衡化
- 图像锐化
- 形态学处理
- 轮廓检测

要求：

1. 编写算法函数。
2. 添加界面参数。
3. 加入处理流水线。
4. 添加算法原理说明。
5. 提交处理前后对比图。

这样可以把项目从“使用 OpenCV”进一步扩展到“理解并实现图像处理实验”。
